# docs.admin.digital

Benutzer-Dokumentation fuer admin.digital, erstellt mit [MkDocs](https://www.mkdocs.org/) und dem [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) Theme.

## Lokale Entwicklung

```bash
make install
make serve
```

## Deployment

Automatisch via GitHub Actions bei Push auf `main`.

Manuell: `make deploy`

**URL:** [https://docs.admin.digital](https://docs.admin.digital)
