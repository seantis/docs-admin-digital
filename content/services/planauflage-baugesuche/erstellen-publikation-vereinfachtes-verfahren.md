# Erstellen einer Publikation im vereinfachten Baubewilligungsverfahren

Diese Anleitung beschreibt, wie du eine Online-Publikation eines Baugesuches im vereinfachten Baubewilligungsverfahren erstellst und den Zugriff konfigurierst.

## 1. Allgemeines

Beim vereinfachten Baubewilligungsverfahren wird der Zugang zu der Online-Publikation des Baugesuches nur den direkten Anstössern ermöglicht. Im vereinfachten Baubewilligungsverfahren publizierte Baugesuche sind öffentlich nicht sichtbar.

Den direkten Anstössern wird per Brief oder Mail ein QR Code der URL der Publikation des Baugesuches zugestellt. Über die URL kann ein Code für die Einsicht der Online-Publikation abgerufen werden. Für den Erhalt eines Codes muss sich der Nutzer mit seiner Mobiltelefonnummer identifizieren.

Das Erstellen einer Online-Publikation von Baugesuchen im vereinfachten Baubewilligungsverfahren unterscheidet sich nur bezüglich Konfiguration des Zugriffs. Aus diesem Grund wird nur die Konfiguration des Zugriffs beschrieben.

## 2. Konfiguration Zugriff

1. Wähle unter «Zugriff» die Option «Nur wer die URL kennt nach Eingabe eines mTANs». Damit wird der Passwortschutz des Verzeichniseintrags aktiviert.
2. Wähle «Absenden». Der Verzeichniseintrag wird gespeichert.

## 3. Erstellen QR Code

1. Öffne den Verzeichniseintrag (Baugesuch).
2. Wähle die Funktion «QR» im Admin Balken. Es wird ein QR Code der URL generiert, der heruntergeladen werden kann.
3. Stelle den QR Code den zu informierenden Anstössern per Brief oder E-Mail zu.

Die Publikation kann nur mittels Eingabe eines Codes abgerufen werden. Für den Erhalt eines Codes muss sich der Nutzer mit seiner Mobiltelefonnummer identifizieren. Der Code wird mittels SMS zugestellt und ist 5 Tage für maximal 50 Zugriffe gültig (pro Tag max. 10).
