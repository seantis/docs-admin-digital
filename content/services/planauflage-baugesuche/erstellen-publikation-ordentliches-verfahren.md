# Publikation erstellen (ordentliches Verfahren)

Mit dieser Anleitung erstellst du eine Publikation im ordentlichen Baubewilligungsverfahren, bearbeitest bestehende Einträge und exportierst oder importierst Daten.

## 1. Voraussetzungen

1. Melde dich bei admin.digital mit den benötigten Benutzerrechten an. Dazu benötigst du einen für dich konfigurierten YubiKey.
2. Nach der Anmeldung wird ein Bearbeitungsbalken mit den Auswahlmöglichkeiten «Konfigurieren», «Export», «Import», «Löschen», «Hinzufügen» und «QR» angezeigt.

## 2. Publikation hinzufügen

1. Klicke auf «Hinzufügen» und wähle «Eintrag». Die Seite «Neuer Verzeichniseintrag» wird geöffnet.
2. Fülle die Pflichtfelder (mit * markiert) aus. Nicht ausgefüllte Pflichtfelder verhindern das Speichern des Eintrages. Die Felder umfassen:
    - *Gesuchsteller/in*
    - *Grundeigentümer/in*
    - *Planverfasser/in*
    - *Bauvorhaben*
    - *Adresse*
    - *Grundstück-Nr*
    - *Auflagefrist von*
    - *Auflagefrist bis*
3. Lade unter «Anhänge» die gewünschten Dateien hoch: Klicke auf «Dateien auswählen», wähle die Datei im Explorer und bestätige mit «Öffnen». Die gewählte Datei wird unter «Anhänge» angezeigt.
4. Definiere unter «Publikation» den Zeitraum «Von» / «Bis», in welchem die Publikation öffentlich eingesehen werden kann. Dieser Zeitraum kann unter bestimmten Gründen vom Zeitraum der Auflagefrist abweichen.
5. Gib unter «Koordinaten» die Adresse des Bauvorhabens ein und klicke auf «Nach Adresse suchen». Der Standort wird auf einem Kartenausschnitt angezeigt.
6. Wähle unter «Zugriff» bei Bedarf «Zeitbegrenzter Zugriff», um den Passwortschutz des Verzeichniseintrags zu aktivieren. Publikationen können dann nur mittels Eingabe eines Codes abgerufen werden. Der Nutzer identifiziert sich mit seiner Mobiltelefonnummer und erhält den Code per SMS. Der Code ist 5 Tage lang gültig, für maximal 50 Zugriffe (pro Tag max. 10).
7. Klicke auf «Absenden», um den Verzeichniseintrag zu speichern.

## 3. Publikation bearbeiten

1. Nach dem Speichern eines Verzeichniseintrages werden im Bearbeitungsbalken die Auswahlpunkte «Bearbeiten» und «Löschen» angezeigt.
2. Klicke auf «Bearbeiten». Der Verzeichniseintrag wird geöffnet und die Inhalte können bearbeitet werden.
3. Bezüglich Anhänge kannst du entscheiden, bestehende Anhänge zu behalten, zu ersetzen oder zu löschen.
4. Klicke auf «Absenden», um den Verzeichniseintrag zu speichern.

## 4. Publikation löschen

1. Nach dem Speichern eines Verzeichniseintrages werden im Bearbeitungsbalken die Auswahlpunkte «Bearbeiten» und «Löschen» angezeigt.
2. Klicke auf «Löschen». Ein Bestätigungsfenster wird geöffnet.
3. Bestätige mit «Verzeichnis löschen», um den Verzeichniseintrag endgültig zu löschen.

## 5. Daten exportieren

1. Klicke im Bearbeitungsbalken auf «Export».
2. Wähle das gewünschte Format (CSV, Excel, JSON oder XML). Die resultierende Zip-Datei enthält das gewählte Format sowie alle Metadaten und allfällige Bilder/Dateien.
3. Klicke auf «Absenden». Der Export wird generiert und unter «Downloads» im Browser angezeigt.

## 6. Daten importieren

1. Klicke im Bearbeitungsbalken auf «Import». Dies aktualisiert die Konfiguration des Verzeichnisses und importiert alle Einträge gemäss der angegebenen Zip-Datei. Das Format entspricht dem Format des Exports.
2. Wähle unter «Verzeichniskonfiguration anwenden», ob du die Verzeichniskonfiguration und die Einträge oder nur Einträge importieren möchtest. Beachte, dass der Import der Konfiguration die bestehende Konfiguration überschreibt.
3. Wähle unter «Modus», ob alle oder nur neue Einträge importiert werden sollen.
4. Klicke unter «Import» auf «Datei auswählen», wähle die gewünschte Datei im Explorer und bestätige mit «Öffnen». Die gewählte Datei wird unter «Import» angezeigt.
5. Klicke auf «Absenden». Die Daten werden importiert und im Verzeichnis angezeigt.

## 7. Konfiguration

Die Konfigurationsmöglichkeiten werden in einer separaten Anleitung beschrieben. Siehe [Konfiguration Startseiteneinstellungen](konfiguration-startseite.md).
