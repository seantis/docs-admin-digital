# Karten

Im Modul **Karten** werden interaktive Karten über verschiedene Kartenanbieter bereitgestellt.

## Verfügbare Kartenanbieter

- Swisstopo (Standard)
- Swisstopo Luftbild
- Mapbox
- Vermessungsamt Winterthur
- ZugMap Basisplan Farbig
- ZugMap Orthofoto
- Geoportal Basel-Stadt

## Integration

Interaktive Karten sind in mehreren Modulen integriert:

- [Veranstaltungskalender](/module/veranstaltungskalender/)
- [Themen und News](/module/themen-und-news/)
- [Verzeichnisse](/module/verzeichnisse/)
