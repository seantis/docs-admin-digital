# Schnittstelle GEVER

Die OneGov GEVER API ermöglicht die Anbindung an GEVER-Systeme. Dadurch können Dokumente direkt aus [Service Tickets](/module/service-ticketing/) an das Geschäftsverwaltungssystem übertragen werden.

In Tickets steht dafür die Option **„Hochladen auf GEVER“** zur Verfügung.

## Funktion

- Ein Ticket kann per Knopfdruck an ein GEVER-System übermittelt werden.
- Die PDF-Version des Tickets wird automatisch generiert und anschliessend hochgeladen.

## Einrichtung

Voraussetzung ist, dass die **API-Credentials** in den Einstellungen hinterlegt werden (einmalig).

## Nutzung

Sobald die API-Credentials gespeichert sind, können Dokumente hochgeladen werden. Die Dokumente werden an den GEVER-Endpunkt gesendet und können dort weiter zugeordnet werden (z.B. über den Eingangskorb).

## Unterstützte GEVER-Systeme

Als erstes GEVER-System wurde die digitale Geschäftsverwaltung **OneGov GEVER** der Fabasoft 4teamwork AG angebunden. Schnittstellen zu weiteren Geschäftsverwaltungssystemen sind geplant.

- Bezug: [Service Ticketing](/module/service-ticketing/)
