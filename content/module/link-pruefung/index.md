# Link-Prüfung

Mit dem Modul **Link-Prüfung** werden Links auf der Seite überprüft und fehlerhafte Verweise erkannt.

## Was wird geprüft?

- **Interne Links**: Links innerhalb des Portals (z.B. auf Unterseiten oder Inhalte).
- **Externe Links**: Links auf externe Websites.

Die Link-Prüfung kann auch Links prüfen, die auf andere Seiten führen (intern oder extern). Externe Links hängen von der Erreichbarkeit der Zielseite ab. Je nach Zielsystem kann die Prüfung länger dauern oder temporär fehlschlagen.
