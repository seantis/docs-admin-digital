# Module

admin.digital bietet eine Reihe von Modulen, die speziell auf die Bedürfnisse der öffentlichen Verwaltung in der Schweiz zugeschnitten sind. Jedes Modul deckt einen bestimmten Verwaltungsbereich ab und kann einzeln oder in Kombination eingesetzt werden.


<div class="grid cards" markdown>

-   :material-form-select:{ .lg .middle } **Formulare**

    ---

    Erstellung und Verwaltung von digitalen Formularen für verschiedene Verwaltungsprozesse.

    [:octicons-arrow-right-24: Mehr erfahren](/module/formulare/)

-   :material-desktop-classic:{ .lg .middle } **Online-Schalter**

    ---

    Digitale Anlaufstelle für Bürgerinnen und Bürger. Ermöglicht die Einreichung von Gesuchen und Anträgen über das Internet.

    [:octicons-arrow-right-24: Mehr erfahren](/module/online-schalter/)

-   :material-poll:{ .lg .middle } **Umfragen**

    ---

    Erstelle Umfragen analog zu Formularen – ohne Ticket-Erstellung. Die Resultate kannst du direkt herunterladen.

    [:octicons-arrow-right-24: Mehr erfahren](/module/umfragen/)

-   :material-link-variant:{ .lg .middle } **Link-Prüfung**

    ---

    Überprüfe interne und externe Links – auch solche, die auf andere Seiten führen.

    [:octicons-arrow-right-24: Mehr erfahren](/module/link-pruefung/)

-   :material-calendar-outline:{ .lg .middle } **Reservationen**

    ---

    Verwaltung von Raumreservationen, Ressourcen und Buchungen für öffentliche Einrichtungen.

    [:octicons-arrow-right-24: Mehr erfahren](/module/reservationen/)

-   :material-credit-card-outline:{ .lg .middle } **Online Bezahlung**

    ---

    [:octicons-arrow-right-24: Mehr erfahren](/module/online-bezahlung/)

-   :material-dots-horizontal-circle-outline:{ .lg .middle } **Themen und News**

-   :material-account-multiple:{ .lg .middle } **Benutzerverwaltung**

    ---

-   :material-ticket-confirmation-outline:{ .lg .middle } **Service Ticketing**
